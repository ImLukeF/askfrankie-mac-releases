# AskFrankie for Mac

Download the latest ZIP from [Releases](https://github.com/ImLukeF/askfrankie-mac-releases/releases/latest); unzip it, then drag AskFrankie to Applications. Sign in with your AskFrankie account and the Mac connects automatically. Native connection, Messages, voice and permission controls live in AskFrankie Settings. Updates arrive automatically in-app.

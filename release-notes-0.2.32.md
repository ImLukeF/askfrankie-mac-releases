# AskFrankie for Mac 0.2.32

Native notifications for Frankie replies, new unread inbox messages and due reminders. Enable them in AskFrankie Settings → Notifications and allow alerts in macOS System Settings. Tapping an alert opens its item in the matching signed-in workspace.
